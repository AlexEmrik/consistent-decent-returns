# decent_returns

Long only portfolio optimization to achieve consistent, decent returns via convex optimization.

---

## Some notes

All the factor data comes from [Ken French's data library](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)
*except* for the minimum volatility factor, which comes from [MSCI's website](https://www.msci.com/indexes/index/139133).

The ETF data and economic data is automatically downloaded from Yahoo Finance and FRED, respectively using `scripts/setup.py`.

## Core workflow

0. If you don't have uv installed, run `make uv` to install it. We use `uv` to manage the Python environment.
1. Run `make setup` to set up the Python environment and install the pre-commit hooks (keeps code quality high).
2. Add your [FRED API key](https://fred.stlouisfed.org/docs/api/api_key.html) to `keys/fred_api.key`:
   ```bash
   echo YOUR_KEY > keys/fred_api.key
   ```
3. Run `python scripts/1_download_data.py` once to download all raw data and compute the shared processed artifacts (full-universe risk model, base universe, uncertainty files and return &macro features).
4. Run `python scripts/2_setup_configs.py` once to build risk models, alphas, and JSON configs for all benchmark strategies. Requires step 3.
5. Define additional backtests in JSON files under `configs/` as needed. See `SIMULATOR.md` for full documentation.
6. Run backtests with `python scripts/3_run.py`. Use `--all` for everything, or `-f <file>` for a specific config file.
7. Visualize the results via `marimo run notebooks/result_visualization.py`.
8. To remove generated artifacts, use `python scripts/clean.py`. See `--help` for available tiers.

As is, there are two separate but related projects within this repository:

1. Identifying simple portfolio strategies that yield greater returns than a 60/40 portfolio (with small drawdowns).
2. Using machine learning methods to generate alphas for use in a modern Markowitz-at-seventy portfolio construction method.

## Project Structure

```text
decent_returns
├── src/
│   ├── decent_returns/      # Core module + computational logic
├── notebooks/               # Notebooks, primarily for visualization
├── scripts/
│   ├── 1_download_data.py   # Download raw data + build shared processed artifacts
│   ├── 2_setup_configs.py   # Build benchmark risk models, alphas, universes, and configs
│   ├── 3_run.py             # Run backtests (--all / --bench / --nd / -f)
│   ├── clean.py             # Remove generated artifacts (--results / --processed / --all)
│   └── profile_simulator.py # Developer profiling tool
├── paper/                   # Paper
├── configs/                 # Backtest configuration files (generated by setup scripts)
├── SIMULATOR.md             # Backtest simulator documentation
└── data/                    # Data, processed and raw
```
